# Contributing / 贡献说明

感谢反馈。提交 Issue 请说明系统、Agent、复现步骤及预期行为，不上传密钥、私人素材或完整本地项目数据库。

本项目采用个人非商用许可。提交原创贡献时，请在 PR 中明确确认你有权提交，并同意原作者将该贡献按本仓库许可分发，以及另行提供商业授权。没有该明确同意的贡献，在厘清授权前不合并。不接受从其他项目复制且许可不兼容的代码、模型权重或未经授权的素材。

Please describe the environment and reproduction steps. Do not include secrets or private media. For an original contribution, explicitly confirm in the PR that you have the right to submit it and authorize the original author to distribute it under this repository's license and provide separate commercial licenses. Contributions without that explicit permission will not be merged until licensing is resolved. Do not submit incompatible third-party code or unauthorized assets.
