# 老董智能剪辑 laodongcut

参考喜欢的视频风格，把自己的口播做成一条好看的干货视频。

这是按产品方案 v0.6 实现的首版可运行 Skill。页面延续指定原型的“拆解模板／我的视频”两种工作区，使用真实本机文件、持久任务和 MP4 渲染，不含模拟 Agent 返回按钮。

## 安装与开始使用

下载压缩包，直接拖进 Agent 对话，说：**“帮我安装这个 Skill，并带我开始使用。”** 不需要自己解压或选择目录。Agent 会检查安装情况、处理安装、检查依赖，并优先在对话旁的内置浏览器打开工作台，逐步引导使用。

后续更新：把新版压缩包拖进 Agent 对话，说：**“帮我更新这个 Skill，保留已有项目和素材。”** Agent 会先检查已有安装，再备份程序并更新，保留项目数据。

以后打开，说 **“打开老董智剪。”** 没有出现页面时，说 **“请在当前 Agent 的内置浏览器里打开老董智剪工作台。”**

宿主需支持读取附件、本机文件和命令；不支持时 Agent 会说明替代操作。Node.js 20+、完整 FFmpeg（含 libass）、FFprobe、中文字体由 Agent 检查；缺少权限或能力时说明。各宿主并未全部验证。制作仍通过页面复制要求、粘贴回当前对话接续。

安装器供 Agent 从临时解压目录运行：`node scripts/install.mjs [实际安装目录]`。默认 Codex 目录，其他宿主先核实路径。更新前备份程序并检查运行任务，保留数据与配置。启动和制作细节见 SKILL.md。

## 数据与恢复

默认保存在本包 `data`。使用 `--data` 或 `LAODONGCUT_DATA` 指定独立目录，可在更新 Skill 时继续复用。正式模板、项目与意见不依赖浏览器缓存。清浏览器缓存后从首页项目列表继续。

备份整个数据目录，其中包含原文件副本、逐句转写、剪切决定、模板快照、规划、意见、任务和历次渲染。用户原文件不移动、不修改。中断时先运行 `doctor`，确认旧执行进程已退出再按 Skill 指引恢复任务；失败保留上一版视频。

## 实际能力与验收边界

已实现：两个入口、两类意见隔离、真实路径上传、版本模板、持久任务、停顿初检、真实转写导入、粗剪批准、音画同步裁切、内容驱动画面规划、10秒样片与短片全长、审批拦截、完整版及二次修改、完整解码检查、失败恢复。

参考分析、逐句转写、事实判断和修改语义由当前 Agent 实际完成。本地运行时不会自动理解任意参考或随口一句修改。固定渲染器支持知识卡片、清单、步骤、条形图、图片／B-roll、字幕和人物小窗；复杂特效需另行实现并验证。

内置模板和示例采用原创内容，来源见 `examples/说明.md`。它们不代表已完成任意风格的复刻验证。真人口播用合成测试片验证技术链路，尚需真实用户素材和低基础用户独立体验验收。无自动发布、批量制作或平台视频下载。

## v0.2 内置动效模板

新项目默认使用干货讲解竖屏模板 v3（原生1080×1920），规划格式及内容编排规则见 references/content-direction.md。本文旧版 list/steps/focus/media/bar 规划例子只适用于v1；复现旧示例时创建项目加 `--template-version 1`。旧项目快照保持不变。用户要求升级旧项目时使用 `upgrade-builtin <项目ID> --reason "用户要求" --data <数据目录>`，然后通过真实修改任务重新规划和渲染。不得把v1纯文字规划直接用于v3。

通用模板v3默认不生成任何品牌页脚。每条规划需提供按内容设计的theme，背景、分隔线、人物边框和内容元素配色不再固定。
