# 示例来源与使用

本目录的文稿、画面规划和代码画面为本项目原创，本次发布按根目录 LICENSE 的个人非商用许可分发；旧版已合法获得的其他许可不受追溯影响。声音由 Windows 本机 Microsoft Huihui Desktop 逐句合成，非真人声音，不声称使用 ASR。字幕句界取每句实际 WAV 时长。未分发微软语音引擎、字体或任何外部视频。

- `示例讲解.wav`：可在“我的视频”中作为录音上传，测试真实路径交接与制作。
- `示例转写与粗剪.json`：与上述音频对应的真实句界和全句保留决定，可作为用户已提供字幕导入。用户仍须确认粗剪。
- `示例画面规划.json`：覆盖全部实测讲解时长，供 Agent 了解协议；用户自己的素材必须重新规划。
- `前10秒示例.mp4`：实际渲染的10秒 MP4，不是原型动画。
- `原创参考示例.mp4`：可上传为新参考，验证取帧、Agent 拆解、元素审核和模板入库。
- `示例首帧.jpg`：可视检查用。

示例在隔离构建项目中制作，不代替用户视频的粗剪确认与样片审核。内置模板仍标注为原创代码布局，不把示例推断包装成任意参考片的自动分析能力。
